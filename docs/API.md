# API Specification: AI Intelligence Platform for Data Centre EPC Project Delivery

## Base URL
- Backend: http://localhost:8000/api
- Interactive Swagger: http://localhost:8000/api/docs

## Endpoints
- GET /api/health
- GET /api/ping
- POST /api/documents/upload (Phase 4)
- POST /api/chat (Phase 5)
- POST /api/compliance/check (Phase 6)
- POST /api/schedule/upload (Phase 7)
- POST /api/risks/analyze (Phase 7)
- GET /api/dashboard/summary (Phase 8)

# System Architecture: AI Intelligence Platform for Data Centre EPC Project Delivery

## Overview
The Data Centre EPC AI Intelligence Platform serves as an autonomous analytics and compliance layer over complex engineering, procurement, and construction (EPC) projects for mission-critical data centres.

1. **Frontend (Next.js 14 App Router, TypeScript, Tailwind CSS)**
2. **Backend (FastAPI, Pydantic v2, SQLAlchemy 2.0)**
3. **Database & Vector Store (PostgreSQL 16 + pgvector)**
